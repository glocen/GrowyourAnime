## Voidkin names

The director, 2026-11-11: "dont be shy with the name by the way we can use some japanese etc name even if it end up being the name of a MC in a famous anime as long as it doesnt have the same similarities". So a name may come from any language, and a name shared with a published character is fine when the Voidkin shares nothing else with it: not the look, not the move, not the role. A name a work invented for its character stays out.

## Names that never appear in what players see

- The names of published characters, series, studios and their signature moves, in any spelling or near-spelling.
- The names another game clearly invented: its title, its currencies, its creatures, its modes.
- "Eye" for the bay's ring, a light crystal in a round hoop, or for anything in the base (the content check, AR16, 2026-11-16).

A general word of the genre (clan, aura, trait, tower, arena) is free. Internal docs and code comments may name anything.
